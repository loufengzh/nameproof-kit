# Nameproof Kit

Краткая идея продукта → варианты названия → предварительный отчёт с источниками и явными пробелами. Python 3.10+, без зависимостей во время исполнения. Полные схемы: [English README](../README.md).

## Быстрый старт

Из корня репозитория:

```sh
python -m nameproof propose --brief examples/brief.json
python -m nameproof report --brief examples/brief.json --candidates examples/candidates.json --format markdown
python -m nameproof domain example.com --live
python -m nameproof screen --name QuillNest --countries US,EU,VN --classes 9,42
python -m nameproof logo-brief --name QuillNest --brief examples/brief.json
python -m unittest discover -s tests -v
```

Необязательная локальная установка: `python -m pip install .`. Публикация в PyPI не заявлена. По умолчанию сеть не используется; `--live` раскрывает запрашиваемые домены публичным IANA/RDAP-сервисам. Покупок и подачи заявок нет.

## Возможности и ограничения

- Локальная генерация использует английские ключевые слова и метафоры. Для содержательных многоязычных вариантов используйте модель своего агента и передавайте массив объектов `name`, `rationale` через `--candidates`. Оценка удобства написания не измеряет смысловую пригодность, продажи или юридическую безопасность.
- Поля задания: `idea`, `audience`, `tone`, `keywords`, `countries`, `nice_classes`, `tlds`, `max_length`, `avoid`. Страны и классы по умолчанию — явно обозначенные предположения. Максимальная длина является жёстким фильтром; `avoid` исключает нормализованные подстроки.
- RDAP сообщает о записи регистрации, её отсутствии или неизвестном состоянии. Отсутствие записи не означает доступность покупки. Сохраняются источник, время, ошибки и лимиты. Импортированные ответы регистратора остаются непроверенными данными пользователя. Давность более 15 минут или время более чем на 30 секунд в будущем блокируют обновление; противоречия явно отмечаются.
- Сопоставление товарных знаков работает только с предоставленными записями. Есть официальные планы ручного поиска для США, ЕС, Великобритании, Вьетнама, Китая, Германии, России и Сингапура. Реестр компаний, использование в интернете и права на товарный знак — отдельные проверки. Нет записей — нет проверки; отсутствие совпадений в выборке не является разрешением на использование.
- Сравнение Unicode-текста не заменяет фонетический, смысловой, графический анализ, проверку транслитерации и иных прав. Другие классы МКТУ и неактивные записи не исключают риск автоматически. Учитывается связь ЕС и Германии; национальные права других стран ЕС остаются пробелом.
- Консервативная встроенная поддержка IDNA отклоняет преобразования, меняющие написание. При необходимости подтвердите точную ASCII/punycode-форму у реестра. Полная реализация IDNA2008 не заявлена.
- `logo-brief` создаёт задание, а не изображение. Выбранный op7418/logo-generator-skill указан с закреплённой версией; код не включён и не запускается автоматически. Передача данных, платные вызовы и количество изображений требуют отдельного решения: [LOGO.md](LOGO.md).

## Интеграция с агентами

Скопируйте всю папку `skills/nameproof` в каталог навыков проекта и сохраните доступ к CLI. Официальные форматы Claude Code, Codex, Cursor, Antigravity и Grok Build описаны в [HARNESSES.md](HARNESSES.md). Это документированная совместимость формата, не сертификация реального запуска во всех продуктах. Grok chat не равен локальному CLI.

`python -m nameproof mcp` предоставляет четыре инструмента через stdio JSON-RPC: варианты названий, домены, проверка записей знаков и задание для логотипа. HTTP-порт не открывается. Сетевые проверки включаются явно.

Запись знака требует `mark,jurisdiction,classes,source_url,observed_at,record_id,status`; URL не удостоверяет подлинность. WIPO запрещает автоматические запросы; скрейпинга нет. См. [источники и альтернативы](SOURCES.md). Перед существенным использованием названия нужна профессиональная проверка в соответствующей юрисдикции и подтверждение домена регистратором.

MIT относится только к оригинальному коду репозитория. CI проверяет Python 3.10–3.13; сетевые тесты используют имитацию, реальные наблюдения указываются отдельно.

## Получить инструкции для логотипа

`python -m nameproof logo-source --output /path/to/new-directory --fetch` загружает три текстовых файла закреплённой версии и проверяет SHA-256. Каталог должен быть новым; перезаписи, установки навыка и исполнения скриптов нет. Прочитайте `UPSTREAM_SKILL.md` и ссылки по дизайну, затем создайте оригинальные SVG-концепции средствами агента. Платные изображения требуют отдельного согласования. Без `--fetch` выводится только манифест. См. [пример](WALKTHROUGH.md).
